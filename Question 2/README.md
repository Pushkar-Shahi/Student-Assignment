# Question 2: Personal Resume / Portfolio Webpage

## Question Statement
Design and develop a personal Resume/Portfolio webpage using HTML5 semantic elements. Include sections such as Personal Information, Career Objective, Education, Skills, Projects, and Contact Details.

---

## Aim
To create a clean, accessible resume webpage (`portfolio.html`) using HTML5 semantic elements for optimal document structure and search engine readability.

---

## Semantic Elements Used
| Element | Purpose |
| :--- | :--- |
| `<header>` | Name, title, and top navigation bar |
| `<nav>` | Navigation links that jump to each section via anchor `#ids` |
| `<main>` | Main content container of the page |
| `<section>` | Distinct thematic blocks (Personal Information, Career Objective, Education, Skills, Projects, Contact Details) |
| `<article>` | Self-contained items (such as individual projects or academic qualifications) |
| `<address>` | Semantic container for author contact details (Email, GitHub) |
| `<footer>` | Copyright and ownership notice at the bottom |
