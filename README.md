## 📋 Questions Summary

### [Question 1: Git & GitHub Setup](./Question%201/README.md)
- **Objective**: Explain the steps to set up Git and GitHub. Create a repository, add your first HTML webpage, commit changes, and push to GitHub.
- **Key Concepts**: `git init`, `git config`, `git add`, `git commit`, `git remote`, `git push`, version tracking.
- **Files**:
  - [`Question 1/index.html`](./Question%201/index.html)
  - [`Question 1/README.md`](./Question%201/README.md)

### [Question 2: Resume / Portfolio Webpage](./Question%202/README.md)
- **Objective**: Design and develop a personal Resume/Portfolio webpage using HTML5 semantic elements (Personal Information, Career Objective, Education, Skills, Projects, Contact Details).
- **Key Concepts**: Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`), responsive CSS typography, in-page anchor navigation.
- **Files**:
  - [`Question 2/portfolio.html`](./Question%202/portfolio.html)
  - [`Question 2/index.html`](./Question%202/index.html)
  - [`Question 2/README.md`](./Question%202/README.md)

### [Question 3: Student Registration Form with Validation](./Question%203/README.md)
- **Objective**: Design and develop an HTML registration form using different input types, form elements, and HTML validation attributes.
- **Key Concepts**: Diverse input types (`text`, `email`, `tel`, `date`, `radio`, `checkbox`, `number`, `url`, `file`, `password`, `select`, `textarea`), validation attributes (`required`, `minlength`, `maxlength`, `min`, `max`, `pattern`, `title`, `accept`), CSS `:valid` / `:invalid` states.
- **Files**:
  - [`Question 3/registrationForm.html`](./Question%203/registrationForm.html)
  - [`Question 3/index.html`](./Question%203/index.html)
  - [`Question 3/README.md`](./Question%203/README.md)

### [Question 4: Transitions, Animations, Media Queries & Scroll Reveal](./Question%204/README.md)
- **Objective**: Enhance the landing page with CSS transitions, keyframe animations, mobile-first media queries, reduced-motion accessibility, and scroll reveal.
- **Key Concepts**: GPU accelerated `transform`/`opacity` transitions, `@keyframes` (`rise`, `pulse`, `spin`), CSS spinner, mobile-first breakpoints (768px, 1100px), `prefers-color-scheme: dark`, `@media print`, `prefers-reduced-motion`, JavaScript `IntersectionObserver`.
- **Files**:
  - [`Question 4/index.html`](./Question%204/index.html)
  - [`Question 4/style.css`](./Question%204/style.css)
  - [`Question 4/app.js`](./Question%204/app.js)
  - [`Question 4/NOTES.md`](./Question%204/NOTES.md)
  - [`Question 4/README.md`](./Question%204/README.md)
